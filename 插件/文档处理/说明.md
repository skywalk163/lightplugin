# 文档处理 · 复刻任务卡

- **对标 dsh**：`packages/document`
- **能力**：PDF/Word/Excel/PPT → 文本/Markdown
- **缺口核验**：仅 office转PDF（只做 Office→PDF），无读取与转换
- **优先级**：P0　**批次**：第 1 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `文档大纲`（提取 Markdown 标题大纲）。
- **验证**：`测试_文档处理.light` 13 组全过（扩展名、8 类文档类型判定、转换器必要性、
  转换命令编造、清洗、按行分块、Markdown 大纲 1~6 级、CSV 解析、
  转换器注入成功/失败、未注入转换器、未知类型、文件缺失、挂载端到端）。
- **踩坑**：变量名用中文数字 `六` 会被当整数字面量 → `6[0]` 报 int is not subscriptable
  （LP-D-003），已改名为 `最深`。
- **已知缺口（如实）**：
  - 扩展名判定**大小写敏感**，`.PDF` 会判为未知。
  - 二进制文档（pdf/word/excel/ppt）的实际抽取**依赖注入的转换器**
    （宿主接 pdftotext / LibreOffice / python 脚本），本插件不内置解析能力。
  - 未做合并单元格、公式、图片等精解析；分块按行而非按字符数。
