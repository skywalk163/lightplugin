## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `判定类型` / `校验结构`。
- **判型**：直接用光明内置 `是空/是整数/是浮点/是字符串/是列表/是字典`。
  **判型顺序里「真假」必须排在整数、浮点之后** —— `是整数` 已排除 bool，
  而 `0 == 假` 在光明里成立，若先判真假会把 `0` 误判成「真假」（已写成断言守住）。
- **验证**：`测试_类型运行时.light` 18 组全过（七类类型判定 + `0` 应判整数、类型名合法性、
  纯数字串/浮点串守卫、结构校验全命中、可选字段缺失放行、必填缺失反例、类型不符反例、
  一次收集全部问题、任意类型放行、目标非映射与字段表非列表两组反例、
  转换 文本/整数/浮点/真假 四向正例与非数字串等反例、注入转换器优先与转换器拒绝，
  以及「挂载进注册表后取出工具执行」的端到端，含缺字段、必填缺失、类型不符三组反例）。
- **踩坑（已登记到 数据集/_err_agentJ.jsonl）**：
  ① 内置 `是数字("7")` 实测返回 **假**（源码注释写的是 str.isdigit，实际语义是「值是数字」），
     静默与直觉相反 → 字符串守卫改用自写的 `是纯数字串`（数字集合法），不依赖它；
  ② schema 描述串里的花括号 `{名字}` 被当插值求值 → 报 `name '名字' is not defined`，已去掉花括号。
- **已知缺口（如实）**：
  - **结构校验只做一层**：不支持嵌套结构递归校验、不支持联合类型（如「整数或文本」）、
    不支持数组元素类型校验、不支持自定义校验谓词。
  - **无 schema 编译/缓存**：字段表每次遍历解释执行，未做编译期优化。
  - **转换不含本地化**：`文本→整数` 只认纯数字串，**不支持负号、下划线、千分位、前导空格**；
    `文本→真假` 只认 “真”/“假”，不认 “true”/“false”/“1”/“0”。
  - **无类型别名与泛型**：类型名是固定九类（含 `任意`），不支持用户注册新类型。
