## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `合并字典` / `去重列表`。
- **内核**：`深拷贝(值)`（字典/列表递归复制，标量原样返回）、`合并字典(基, 覆盖)`（后者覆盖前者，
  值走深拷贝）、`去重列表(表)`（保序）、`扁平化一层(表)`（只摊一层）、`按块切分(表, 大小)`
  （`大小 <= 0` 视为非法返回空）、`列表转串(表)`。全部纯函数，零 I/O。
- **验证**：`测试_通用工具.light` 18 组全过 —— 深拷贝三层互不影响（标量/嵌套列表/嵌套字典）、
  合并覆盖与入参不被污染、空字典合并、去重保序、空列表去重、扁平化只摊一层
  （断言 `type(一层后[1]) == list`）、分块余数与整除、块大小 0 反例、空列表分块反例、
  以及「挂载进注册表后取出工具执行」的端到端（含缺参报错两条反例）。
- **踩坑**：本次无新增光明缺陷。沿用既有约束：循环变量避开与被调用函数同名（LP-D-010）、
  结果列表命名避开「出」（LP-D-013）、字典/列表字面量先赋变量再传（L-047）。
- **补深（本轮横向补深）**：新增 `深合并(基, 覆盖)`（嵌套字典逐层递归合并，列表整体替换，标量覆盖，
  结果不共享入参内部引用，任一侧有环即返回安全空字典）、`有环(值, 已见=空)`（路径栈式循环引用检测，
  同一子树被引用两次的 DAG **不**误判为环）、并给 `深拷贝(值, 已见=空)` 加了环检测保护
  （命中路径上的容器即返回安全空容器，不死循环）。原 `合并字典`（浅）/ `去重列表` 语义未动。
- **已知缺口（如实）**：
  - ~~无 `deepMerge`（嵌套字典是整体覆盖）~~ → **已补** `深合并`；但对齐的是 lodash.merge 语义的子集：
    列表是**整体替换**（不做按索引逐项合并、不去重），`空` 值覆盖行为未做 lodash 的 undefined 跳过处理。
  - ~~无循环引用检测：自引用字典递归会栈溢出~~ → **已补** `有环` + `深拷贝` / `深合并` 环保护。
    取舍：命中环时**返回安全空容器**（`{}` / `[]`）而不是抛错，调用方需自行判空；
    检测基于「当前递归路径栈」，`已见` 可复用传入，路径外的重复子树会被正常复制两次。
  - `按块切分` 不做元素类型校验；`扁平化一层` 只摊一层（与 dsh `flatten` 的「一层」语义一致，非深摊）。
  - `深拷贝` / `深合并` 只覆盖 dict / list 两类容器；类实例、函数、集合等按标量原样返回（**共享引用**）。
  - 新增段落为库函数层，**未注册为模型可见工具**（`挂载` 签名与工具数量保持不变，避免 `集成/工具总表.json` 失配）。
