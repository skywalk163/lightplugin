## 复刻记录

### 挂接方式

- `从 异步作业轮询 导入 提交作业, 查询作业, 完成作业, 轮询直到终态`（复用 P0-1 底座）
- `挂载(注册表, 识别器=空)` 注册工具名 **`语音转文字`**
- 识别器签名 `(音频, 语言, 要时间戳) -> ["完成": 真假, "稿本": 串, "原因": 串]`
  返回键叫「稿本」而非「文本」—— 含「文本」的标识符会被词法器拆名（L-044）

### 为什么是"三包合一"

dsh 侧实际有三个包：`speech-to-text` / `api-speech-to-text` / `speech-to-text-sensevoice`，
是**同一能力的三种后端**。本插件收敛为「一份契约 + 可切换后端」，
不为每种后端各写一套作业编排。

### 相对图片/三维生成的增量：分段转写

长音频必须切片，每段一个作业，最后按序合并 —— 图片/三维没有**顺序敏感的产物拼接**问题。
核心语义：**任一段失败即整体失败**，绝不做部分交付（半截稿本比没有更危险）。

### 验证结果

`测试_语音转文字.light` **9 组全部通过**（一次跑通）：切分（含末段截断/整除/非法）/ 语言校验 /
单音频转写成功 / 永不成功超时 / 分段全成按序归并 / **含坏段时整体失败且完成段数=0** /
非法时长 / 工具层单段与分段两条路径 / 未绑定识别器报错。

### 已知缺口（如实）

- **不内置任何真实 ASR 服务**，识别器由宿主注入。
- **分段不重叠**：段边界硬切，没有做重叠窗口 → 段边界处的词可能被切断。
  真实 ASR 通常取 0.2~0.5 秒重叠再做去重合并，本版未做。
- **不做标点与大小写还原**：直接按识别器返回的串拼接。
- **语言白名单只有 zh/en/ja/auto**，未配置化。
- **时间戳未真正实现**：`要时间戳` 参数透传给识别器，但本模块不解析/不校验时间戳结构。
