## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露 2 个工具：
  `构造ACP请求` / `校验ACP消息`。消息结构按 JSON-RPC 2.0 风格装配/校验，零网络。
  真实传输（WebSocket / stdio 帧）由宿主负责（注入式），本插件只做消息结构的纯逻辑。
- **验证**：`测试_协议ACP.light` 全过（请求/响应/错误响应/事件装配字段断言、合法消息类型判定、
  5 类非法消息反例：缺 jsonrpc / 请求带 result / jsonrpc 版本错 / 响应双含 result+error / 响应两者皆无、端到端 构造→序列化→校验）。
- **踩坑**：无新增光明编译/运行报错；`序列化JSON` / `解析JSON` / `字符串获取` 等 stdlib 均已验证可用。
- **已知缺口（如实）**：
  - 对齐 ACP 的 JSON-RPC 形态，未覆盖 ACP 特有的**批量请求 / 通知流控 / 分片帧**等上层协议细节。
  - 校验为**结构层**校验（jsonrpc 版本、id/method/result/error 组合），未做 `method` 白名单或参数 schema 深度校验。
