# 终端会话 · 复刻任务卡

- **对标 dsh**：`packages/terminal`
- **能力**：终端会话交互：开会话/写输入/读输出/关闭，pty 状态机
- **缺口核验**：完全无（terminal 0 命中）；工具_bash 只做一次性执行，无会话
- **优先级**：P6　**批次**：第 7 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露 4 个工具：`打开终端` / `写入终端` / `读取终端` / `关闭终端`。真实 pty 由模块级注入式 `设定驱动(函数)` 提供（宿主接真实伪终端，测试传真回显/命令响应），实现零真实进程、零计时 flaky。
- **验证**：`测试_终端会话.light` 全绿（退出码 0、含「全部通过」）。覆盖：端到端注册 4 工具、状态机 新建→运行→关闭、回显命令响应（echo/whoami）、累积输出顺序、关闭清空、反例（向已关闭会话写 / 读写关闭均报错）、默认驱动回显。
- **踩坑**：① `全局 X。` 声明须早于函数内首次引用（测试里 `收到` 先赋值后补 `全局` 触发 “used prior to global declaration”，挪到 `主` 开头即解）；② 模块级标量（pty驱动/序号/存在判定/事件源）凡在段落内重绑必须 `全局`，仅就地改字典内容可省；③ 无 `continue` 关键字 → 用 `跳过` 标志模拟。
- **已知缺口（如实）**：
  - 状态机只有 新建→运行→关闭 三态，未实现「挂起/恢复」「多会话并发输出交错」等 dsh 高级交互。
  - 真实 pty 行为（行编辑、信号、窗口大小协商）完全依赖宿主驱动注入，本插件不内置任何伪终端语义。
  - 会话缓冲为内存字符串累积，无大小上限/回绕，超长会话在宿主侧需自行截断。
