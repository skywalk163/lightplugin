# 运行时Python · 复刻任务卡

- **对标 dsh**：`packages/experimental/ptc-runtime-python`
- **能力**：Python 运行时桥：脚本装配/命令构造/结果解析，注入式执行器
- **缺口核验**：完全无（ptc-runtime-python 0 命中）
- **优先级**：P8　**批次**：第 9 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `执行Python脚本`。
  入口段落 `挂载(注册表)` 返回 `真`。
- **三段式**：`装配脚本(源码, 序言)`（加编码声明 + `import sys` 头，序言排在源码前）
  → `构造命令(脚本, 解释器)`（`python -u -c <脚本>`）
  → `解析结果(退出码, 标准输出, 标准错误)`（退出码 0 判成功，摘要只带标准输出；
  非零则摘要只带标准错误）。
- **注入式执行器**：`设置执行器(执行器)` / `执行脚本(源码, 执行器, 解释器, 序言)`；
  未注入返回 `未注入执行器`，非零退出码返回 `脚本退出码非零: N`。
- **验证**：`测试_运行时Python.light` 11 组全过（装配内容、序言顺序、命令构造与解释器透传、
  成功/失败结果解析、空脚本与纯空白脚本反例、未注入执行器反例、注入后调用计数与命令内容、
  非零退出码反例、以及注册表端到端含成功与失败两条路径）。
  运行：`python 运行.py 插件/运行时Python/测试_运行时Python.light` → 输出「测试_运行时Python 全部通过」。
- **已知缺口（如实）**：
  - **不起真实子进程**：不 fork `python`、不捕获真实 stdout/stderr，执行全部由注入执行器代劳。
  - `-c` 方式传脚本：含引号/多行的复杂脚本在真实 shell 下需要额外转义，本侧**不做转义**。
  - 无超时、无输出长度截断、无工作目录/环境变量/虚拟环境选择（只有解释器名）。
  - 不解析异常栈、不做结构化输出（JSON 协议）与变量回传，只有退出码 + 两条流。
  - 无沙箱隔离与危险调用拦截；dsh 侧的 PTC 安全策略未复刻。
