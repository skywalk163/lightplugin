## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 连接器=空)` 注册工具名 **`桌面驱动CUA原生`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`（须显式，见 LP-D-002）。

### 设计：相对 dsh 的有意差异

CUA 原生格式是「模型直接吐出的计算机操作指令」（如 `{type:click, x, y}`，对应 Anthropic computer-use / OpenAI CUA）。
本复刻版只复刻**翻译层**：把桌面操作意图映射为**原生 CUA 动作对象**（无 MCP 包装），模型可直接消费。
真实执行（截图识别 + 输入注入）由宿主的 CUA 运行时负责，不碰屏幕 / 不碰输入。与 `桌面驱动CUA协议` 互补（协议版带 `mcp__cua__computer` 包装）。

### 验证结果

`测试_桌面驱动CUA原生.light` **8 组全部通过**：截图 / 点击(x,y) / 输入(text) / 按键(key) / 滚动(scroll_amount) / 移动 / 未知动作标跳过 / 翻译序列 / 挂载与工具（未知动作报错）。

### 已知缺口（如实）

- **不连 CUA 运行时 / 屏幕 / 输入**：不校验坐标越界、按键名合法性、滚动方向。
- **参数只做透传**：x / y / text / key / scroll_amount 不校验格式。
- 不处理连续拖拽、等待截图后再决策等 multi-step 编排（那属于 CUA 运行时层）。
