## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 连接器=空)` 注册工具名 **`浏览器驱动DevTools`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`（须显式，见 LP-D-002）。

### 设计：相对 dsh 的有意差异

dsh 真实插件经 chrome-devtools-mcp 上游工具驱动 Chromium（CDP over WebSocket）。
本复刻版只复刻**翻译层**：把与浏览器无关的「动作意图」映射到 CDP 方法名（`Page.navigate` / `DOM.querySelector` / `Input.dispatchMouseEvent` / `Page.captureScreenshot` / `Runtime.evaluate` 等）与参数结构。
真实 CDP 连接由宿主注入「连接器」，不碰浏览器进程、不碰 WebSocket。与 `浏览器驱动Playwright` 互补（Playwright 翻成 `mcp__playwright-mcp__*` 工具名，本插件翻成 CDP 原生消息）。

### 验证结果

`测试_浏览器驱动DevTools.light` **9 组全部通过**：各动作翻译（打开→`Page.navigate` / 点击→`DOM.querySelector`+两次 `Input.dispatchMouseEvent` / 填表→`DOM.querySelector`+`DOM.focus`+`Input.insertText` / 截图 / 抽取→`Runtime.evaluate` / 滚动→`mouseWheel`）/ 未知动作标跳过 / 翻译序列扁平化（1+3+1=5 条 CDP 消息）/ 渲染 / 挂载与工具（未知动作报错）。

### 已知缺口（如实）

- **点击/填表的 x,y 为占位 `0,0`**：真实实现应由 DOM 节点 box model 计算坐标，本复刻不碰浏览器故留占位。
- **不连 CDP / WebSocket / 浏览器**：不校验 selector 有效性、不做坐标越界校验。
- **抽取用 `Runtime.evaluate` 的 `document.querySelector(...)` 字符串**：未做选择器转义。
