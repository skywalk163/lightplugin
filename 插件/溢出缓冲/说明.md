## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `写入缓冲` / `读取缓冲`。
- **注入式写入器**：`装载写入器(写入器)` 注入，契约 `写入器(编号, 分片序号, 分片内容) -> 真假`。
  测试注入只记账的 fake → 零磁盘、零计时。
- **验证**：`测试_溢出缓冲.light` 18 组全过（阈值边界「等于阈值不算溢出」、整除/不整除分片、
  重组还原、未超阈值走内存不落盘、超阈值分片并落盘、写入器失败则不标记落盘但仍可读回、
  无写入器时分片不落盘、反例 空内容/非字符串/负阈值/零阈值/负片大小/读不存在的缓冲，
  以及「挂载进注册表 → 写入 → 从工具输出解析编号 → 读回」的端到端）。
- **踩坑**：全局内置 `切片` 在 `lightplugin/运行.py` 的搜索路径下**未注册**
  （`name '切片' is not defined`）→ 分片改用 `字符串获取(内容, 下标)` 逐字符拼接绕开。
  分片用字符计数而非字节，与 dsh 侧按字节切分在多字节字符上会有差异（见缺口）。
- **已知缺口（如实）**：
  - **无真实落盘**：本模块不碰磁盘，只定义并驱动写入器契约；宿主没注入写入器时分片只留在内存。
  - **按字符而非按字节切分**：阈值/片大小都以字符数计，多字节字符下与 dsh 按字节的口径不同。
  - **无分片级 CRC / 版本 / 过期清理**：记录常驻进程内字典，进程退出即失；无 TTL 与容量上限。
  - **写入器部分失败**时只标记「未落盘」，不重试、不记录是哪一片失败。

## 复刻记录（R101 增量：spill-policy 共享预算策略层）

> 对齐 dsh `packages/spill/spill-policy`（index.ts / retention.ts / notice.ts）：把 0.1.7 新增的
> 「token 预算内联保留策略」补进本插件，作为独立纯逻辑模块 `策略.light`，主文件 `溢出缓冲.light` 不变。

- **新增文件**：`策略.light`（纯逻辑，导入 `lightharness/src/令牌估算.light` 的 `估算内容` 作 token 计价，
  经 `默认价格` 注入；调用方可传自定义 `价格(块)` 注入）、`测试_溢出策略.light`（7 组场景 + 4 组反跑）。
- **核心语义对齐**：文字与图片**共用**一个 `maxInlineTokens` 预算（不各自算）；超预算时按 `retention.ts`
  的 `retainContent` 保留首尾（head+tail）、中间省略；图片整块不可分（预算不足整体跳过，不切碎）；
  完整结果落盘（注入 `写落盘文件`），图片走附件存储（注入 `存附件`）不内联字节；`maxInlineTokens` 为空/0
  时**直通原文**；写盘失败时**降级保留原文**（不抛、不吐空）。
- **notice 文案**对齐 `notice.ts` 的措辞：`(已省略 X 字节[ Omitted Y images.] Full formatted result stored
  at: <locator>. Use read_file to view it.)`。
- **验证**：`测试_溢出策略.light` 全部通过 —— 正例（budget=0 直通 / 未超预算直通 / 超预算 spill 落盘+notice /
  文字+图片共享预算越界 / 首尾保留中间省略 / 写盘失败降级）；反跑 4 组（单点破坏-还原，破坏后必红、还原后必绿）：
  ① 删 `预算<=0` 直通分支 → 预算为 0 不再直通立红；② `图片占位` 改为内联原始字节 → 图片走附件断言立红；
  ③ 组装顺序改成 尾+间隙+头 → 首尾顺序断言立红；④ 写盘失败分支改为返回空内联 → 降级保留原文断言立红。
- **已知缺口（本轮增量，如实）**：
  - **图片占位价为常数 64 token**（`图片令牌占位`）：纯逻辑不接真实模型 `imageRequestPricing`，与 dsh 按
    provider/model 实时计价不同；仅影响「图片何时被整体跳过」的边界，不改变「图片不可切分」的语义。
  - **UTF-16 代理对安全切片**未实现（`文字切片` 按字符切）：astral 字符（部分 emoji / 生僻 CJK 扩展）跨切
    点不回退 1 码元；BMP 字符（含常用 CJK）不受影响。
  - **通知预算预留**用最坏情况估算（总字节 + 总图片数）占位，与 dsh 用 `worstNotice` 预留一致；纯逻辑下
    预算为 0 附近时首尾可能全空（与 dsh 同口径，属预算过小而非缺陷）。
  - 本策略层**未注册为模型工具**（dsh 中它也是 `tools/post-execute` 自动钩子，非模型可调工具）；如需接入
    宿主，由 `溢出缓冲.light` 的 `挂载` 在 Cordis 事件里调用 `保留策略` 即可。
