# 沙箱隔离 · 复刻任务卡

- **对标 dsh**：`packages/sandbox`
- **能力**：沙箱隔离策略：命令/路径/网络风险分级 + 白名单/黑名单裁决
- **缺口核验**：完全无（sandbox 0 命中）；安全守卫策略只做风险分级，无隔离裁决
- **优先级**：P6　**批次**：第 7 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `沙箱裁决`（类别 + 内容 + 可选黑名单/白名单 → 风险分级 + 拒绝/放行裁决）。风险分级按类别 + 关键词启发式纯逻辑实现；黑白名单作为数据注入，零真实进程/磁盘依赖。
- **验证**：`测试_沙箱隔离.light` 全过（命中任一、命令/网络/路径/资源四类风险分级、黑名单拒绝带原因、黑名单未命中放行记录真实风险、白名单按低危放行、可组合批量裁决、挂载端到端）。
- **踩坑**：① 同 接口服务，避免字符串花括号插值；② `子串位置` 须 `从 字符串处理 导入`；③ 光明无已验证的 `含于`，手写 `命中任一` 用 `子串位置(...) >= 0` 判包含。
- **补深（本轮横向补深）**：新增 `分词(命令串)`（空格切词 + 单/双引号整体 + `|` / `>` / `>>` / `&` 分段，返回「段列表」）、
  `规范路径(路径)`（去 `.` 段、合并 `..` 不越根、统一分隔符、去尾斜杠保留根 `/`）、
  `组合裁决(请求, 策略表)`（多策略顺序裁决：任一拒绝即短路；全通过取最高风险等级，返回
  放行 / 等级 / 原因 / 命中策略）、审计三件套 `记审计` / `取审计(数量)` / `清空审计()`（自增序号代替真实时间）。
  `组合裁决(请求表)` 旧签名保留（第二参缺省时走批量裁决），老测试不受影响。
- **已知缺口（如实）**：
  - 风险分级为关键词启发式（高/中/低三档），非 dsh 基于真实 OS/权限上下文的细粒度裁决；新类别未覆盖即归「低」。
  - 黑白名单为精确子串命中，未做正则/通配。
  - ~~可组合策略仅做顺序批量裁决，未实现策略优先级叠加收敛~~ → **已补**：`组合裁决(请求, 策略表)` 支持多策略短路拒绝 + 取最高风险等级；
    但仍未做「策略优先级数值化 + 冲突消解表」（如显式 `deny > allow` 之外的自定义优先级）。
  - **真实 OS 隔离（chroot / namespace / seccomp / 资源限额）不在本模块**：本模块只做「策略与判定层」，
    执行由宿主执行器注入完成（即文档开头的设计取舍）。
  - `分词` 只处理空格、单/双引号与 `|` / `>` / `>>` / `&`；不支持反斜杠转义引号、`$(...)` 命令替换、
    `&&` / `;` / 括号等 shell 语法（`&&` 按两个 `&` 处理，分段结果不变但语义未区分）。
  - 审计日志是**进程内内存表**，不落盘、不持久化；时间序用自增序号代替真实时钟（刻意避开计时 flaky），
    无真实时间戳、无宿主侧审计汇聚。
