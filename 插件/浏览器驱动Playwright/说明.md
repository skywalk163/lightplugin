## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 连接器=空)` 注册工具名 **`浏览器驱动Playwright`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`（须显式，见 LP-D-002）。
- 与 `浏览器自动化` 的关系：它是「动作序列」生产方（打开/点击/填表/截图/滚动/抽取），本插件是同一序列的「Playwright 方言翻译」，互补不重造。

### 设计：相对 dsh 的有意差异

dsh 真实插件经 Playwright MCP 上游工具驱动 Chromium（launch/attach、headless、executablePath）。
本复刻版只复刻**翻译层**：把与浏览器无关的「动作意图」映射到 Playwright 工具名（`mcp__playwright-mcp__browser_*`）与参数结构。真实 MCP 连接由宿主注入「连接器」，不碰浏览器进程。

### 踩到的坑

1. **测试笔误（自查，非语言缺陷）**：测试第 49 行（及渲染分支）`断言True_含(计划2[1]["跳过"], 真, ...)` 把**布尔值**（`跳过` 标记）传给子串包含断言（期望字符串）→ 运行期 `bool.find`。修：改 `断言为真(计划2[1]["跳过"], "未知动作应跳过")`。

### 验证结果

`测试_浏览器驱动Playwright.light` **全部通过**：翻译各动作（打开/点击/填表/截图/滚动/抽取 → 对应 Playwright 工具名与参数）/ 未知动作标 `跳过` / 翻译序列 / 渲染计划（跳过项与正常项分行）/ 挂载与工具（未知动作报错）。

### 已知缺口（如实）

- **不连真实 Playwright MCP / 浏览器**：翻译是静态映射，不校验 selector 有效性、不等待策略。
- **不处理 browser context / 多页 / 弹窗**：单页动作序列假设。
- **参数只做透传**：`url` / `selector` / `value` / `amount` 不校验格式（如 URL 合法性）。
