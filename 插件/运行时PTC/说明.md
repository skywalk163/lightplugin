## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `登记任务槽` / `释放任务槽`。
  入口段落 `挂载(注册表)` 返回 `真`。
- **任务槽**：`登记任务槽(任务名, 资源=1)` 在超过 `配置["容量"]` 时返回
  `["ok": 假, "原因": "容量已满"]`；负资源与空任务名分别返回 `资源需求非法` / `任务名为空`。
  `释放任务槽(槽号)` 归还资源、把生命周期标记为 `已释放` 并从槽表移除。
- **资源账**：`取资源账()` 给出 在用资源 / 累计资源 / 峰值资源 / 登记次数 / 释放次数；
  累计与峰值不因释放而减少。
- **生命周期**：`已登记 → 运行中 → 已完成 / 已失败`，终态不可再推进；释放后进入 `已释放`。
- **注入式执行器**：`设置执行器(执行器)` / `执行槽内任务(槽号, 执行器)`；
  执行前自动推进到 `运行中`，终态槽位拒绝再执行。
- **验证**：`测试_运行时PTC.light` 18 组全过（容量设置、登记正例、空名/负资源反例、
  容量上限反例、资源账累计、释放归还、重复释放反例、生命周期推进与非法推进反例、
  终态判定、释放后标记保留、未注入执行器反例、注入后调用计数与产出、终态槽反例、
  不存在槽反例、以及注册表端到端）。
  运行：`python 运行.py 插件/运行时PTC/测试_运行时PTC.light` → 输出「测试_运行时PTC 全部通过」。
- **已知缺口（如实）**：
  - **不起真实进程 / 线程**，槽内任务一律委托注入的执行器。
  - **资源只用一个抽象额度**（整数），不区分 CPU / 内存 / GPU / 句柄等维度。
  - 无抢占、无优先级调度、无超时回收与死锁检测；容量是静态的，不做动态伸缩。
  - 槽表是**进程内字典**：无跨进程共享、无并发加锁。
  - 无任务取消语义（只能释放），无执行日志与可观测性埋点。
