# 异步作业轮询 · 复刻任务卡

- **对标 dsh**：`packages/jobs`
- **能力**：长任务提交/状态查询/超时/取消
- **缺口核验**：完全无；是图片/视频生成的公共底座
- **优先级**：P0　**批次**：第 1 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `作业状态查询` / `作业取消`。
- **验证**：`测试_异步作业轮询.light` 13 组全过（状态机、取消、失败原因、轮询达成、
  轮询超时、作业不存在、以及"挂载进注册表后取出工具执行"的端到端）。
- **踩坑**：模块级标量写回需 `全局 X。`（否则静默变局部变量）——故作业序号用 `全局`，
  作业表用模块级字典（元素赋值天然共享）。
- **已知缺口（如实）**：
  - **不引真实计时器**，轮询推进靠注入的推进器（这是有意的取舍：规避计时 flaky）。
  - 作业表是**进程内字典**：未做持久化，也未做跨进程共享 / 并发加锁。
  - 无作业清理（TTL）与并发上限。
