# 异步作业轮询 · 复刻任务卡

- **对标 dsh**：`packages/jobs`
- **能力**：长任务提交/状态查询/超时/取消
- **缺口核验**：完全无；是图片/视频生成的公共底座
- **优先级**：P0　**批次**：第 1 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `作业状态查询` / `作业取消`。
- **验证**：`测试_异步作业轮询.light` 13 组全过（状态机、取消、失败原因、轮询达成、
  轮询超时、作业不存在、以及"挂载进注册表后取出工具执行"的端到端）。
- **踩坑**：模块级标量写回需 `全局 X。`（否则静默变局部变量）——故作业序号用 `全局`，
  作业表用模块级字典（元素赋值天然共享）。
- **横向补深（本批）**：新增 `退避间隔` / `更优先` / `移除下标` / `排序作业` / `取下一批` / `批量查询` / `汇总`；
  `提交作业` 增加可选第三参 `优先级`（缺省 0，既有两参调用不受影响），记录新增 `序号` 与 `优先级` 两字段。
  `测试_异步作业轮询.light` 由 12 组扩到 18 组（新增 6 组，含退避封顶/负轮次、优先级降序与同级提交序、
  终态作业不出队、取 0 条、批量查询含不存在作业号、汇总计数 等正反例）。
  状态机与 `轮询直到终态(作业号, 最大轮次, 推进器)`、`挂载(注册表)` 契约均未改动。
- **已知缺口（如实）**：
  - ✅ **已补（横向补深批）**：指数退避 `退避间隔(轮次, 基数, 上限)`（纯数值：`基数 × 2^轮次`，封顶上限，不 sleep）；
    优先级队列（`提交作业(名字, 参数, 优先级=0)` 增加可选优先级字段，`取下一批(数量)` 按优先级降序、
    同级按提交序返回待处理作业）；批量查询 `批量查询(作业号列表)` 与统计 `汇总(作业号列表)`（总数/成功/失败/待处理）。
  - 仍缺：**退避未接入轮询** —— `轮询直到终态` 仍是固定轮次推进，未用 `退避间隔` 计算每轮等待；
    `退避间隔` 只算间隔数、不 sleep（接入需宿主提供真实 sleep 推进器，属有意取舍）。
  - 仍缺：**无抖动（jitter）**，纯 `基数 × 2^轮次` 在多作业同时重试时会同步化（雷同 dsh 侧有 jitter）。
  - 仍缺：作业表是**进程内字典**：未做持久化，也未做跨进程共享 / 并发加锁；
    **真并发受 LP-D-012 阻塞**（光明侧缺少轻量并发/异步表达，见 `../../语言缺陷反馈.md`），
    故 `取下一批` 只能顺序出队，无法并行执行作业。
  - 仍缺：无作业清理（TTL）与并发上限；`取下一批` 每次全表扫描 + O(n²) 选择排序（光明侧无已验证排序内置）。
  - 仍缺（沿用）：**不引真实计时器**，轮询推进靠注入的推进器（有意的取舍：规避计时 flaky）。
