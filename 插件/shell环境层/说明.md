# shell环境层 · 复刻任务卡

- **对标 dsh**：`packages/shell`
- **能力**：shell 环境层：环境变量读写/工作目录/命令解析分片，注入式执行器
- **缺口核验**：基本无；工具_bash 只做一次性执行，缺变量/工作目录/解析层
- **优先级**：P6　**批次**：第 8 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露 3 个工具：
  `设置环境变量` / `获取环境变量` / `解析命令行`。
  环境字典与工作目录为**注入式状态**（模块提供 `装载环境(字典)` / `装载工作目录(目录)` 由宿主或测试注入），
  处理函数为纯逻辑，零网络、零进程、零磁盘；真实命令执行仍由 `工具_bash` 负责，本插件只做变量/目录/解析层。
- **验证**：`测试_shell环境层.light` 全过（环境变量读写原地改写注入字典、工作目录归一含 `.`/`..`/反斜杠、命令行单/双引号与连续空白分片、端到端注册后执行）。
- **踩坑**：`全局 X。` 只能写在**段落体内**；在模块顶层写 `全局` 会报
  「代码生成错误: 「全局」只能写在段落（函数）体内」——模块级标量直接 `设 X 为 ...` 即可，
  仅段落内重新赋值这些标量时才在段落首写 `全局 X。`。
- **已知缺口（如实）**：
  - 引号处理仅支持 `'` 与 `"` 单/双引号配对，**不支持引号内转义**（如 `"a\"b"` 不会被拆开）。
  - 未做环境变量展开（`$VAR` / `%VAR%` 原样保留），与 dsh 的 shell 展开层不完全对齐。
  - 工作目录归一仅为**字符串规整**，不校验真实文件系统存在性（受 p0 契约「不碰磁盘」约束）。
