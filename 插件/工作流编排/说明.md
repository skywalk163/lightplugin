## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `工作流提交`（提交并执行有向步骤图）、`工作流状态查询`。
- **验证**：`测试_工作流编排.light` 16 组全过 —— 串行依赖顺序、并行同层、条件分支剪枝、失败传播（下游跳过）、循环依赖检测、查询不存在反例、挂载端到端（含合法/非法参数）、**重试后成功**、**重试耗尽判失败**、**超时预算充足**、**超预算判超时+超时也走重试**、**汇总聚合**、**取步骤结果**、**取同层批次**、**聚合接口对不存在目标**、**工作流汇总工具端到端**。
- **实现要点**：
  - 步骤字典字段：`id` / `依赖`（前置 id 列表）/ `处理键`（查注入式处理器表）/ 可选 `应失败`（测试用，直接判失败不调处理器）/ 可选 `分支`（{输出值: 目标步id}，步完成后按实际输出剪枝未选中转的下游为「跳过」）。
  - 拓扑分层（Kahn 思想）逐层执行；同层步视为并行语义，但保证上一层全部完成才跑下一层，因此依赖顺序天然成立。
  - 处理器、失败标记、分支、时钟推进器均为**注入式**：宿主登记真处理器/真时钟，测试登记确定性 fake；零网络、零墙上时钟。
  - **重试**：步骤 `重试上限` → 最多再跑 N 次（`执行单步`）；处理器返回 `假` 或超时即失败并重试，重试耗尽才判失败。
  - **超时预算**：`预算轮次` + `推进键`，推进器每轮返回 真/假；耗轮达上限仍未跑完 → 状态 `"超时"`。
  - **聚合**：`汇总` / `取步骤结果` / `取同层批次`；新增模型可见工具 `工作流汇总`。
- **已知缺口（如实）**：
  - ~~无重试~~ → **已补**：步骤可带 `重试上限`，处理器返回 `假` 或判超时时最多再重试 N 次；`记录["步重试"]` / `取步骤结果(...)` 记录每步实际重试次数，`汇总(...)` 给 `重试总次数`。
  - ~~无超时预算~~ → **已补**：步骤可带 `预算轮次` + `推进键`，由 `注册推进器` 注入**确定性时钟**（推进器 `(步, 已耗) -> 真/假`，轮次=推进器被调用的次数，**不取墙上时钟**，故零 flaky）；累计耗轮 >= 预算仍未跑完 → 判状态 `"超时"`，超时同样走重试；每步耗时轮次见 `记录["步耗时"]` / `汇总(...)["耗时"]`。
  - ~~结果聚合不足~~ → **已补**：`汇总(流程号)` 返回 总数/成功/失败/超时/跳过/重试总次数/各步耗时轮次/终态；`取步骤结果(流程号, 步骤名)` 返回单步 状态/输出/重试次数/耗时轮次。
  - **真并发未实现（LP-D-012 阻塞）**：光明侧无已验证的线程/协程原语，同层步骤仍是「按拓扑序串行」。
    本插件只提供 `取同层批次(流程号)`，返回**可被宿主并行化的同层步骤名批次**（每层内互无依赖），
    是否真并发由宿主决定 —— **不假装实现并发**。
  - 分支为「输出值 → 单一下游步」的一元选择，未做多出口 / 权重路由；复杂 DAG 路由需宿主侧扩展。
  - 循环依赖仅检测并拒收，未做「运行期动态回路」支持。
  - 步骤处理器异常未做 try/catch（光明侧 `尝试/捕获` 为保留字不可用），失败用 `应失败` 标志或处理器返回 `假` 模拟，真实运行中处理器抛错会直接中断流程。
  - 重试为「立即重试」，无退避/抖动策略（退避需计时，与「不取墙上时钟」取舍冲突）。
