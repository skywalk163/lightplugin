## 边界：不要重复造轮子

**不发 HTTP、不监听端口**。真实投递（签名校验、重试、HTTP 客户端）由宿主注入 `注入派发器`。
与「钩子总线」的分工：钩子总线是**进程内同步事件总线**（注册钩子 / 触发事件）；
本插件是**外部事件 → 处理器**的登记与派发，工具名前缀 `Webhook` 以示区分（避免与既有工具重名）。

## 复刻记录

- **挂接**：暴露 4 个工具：`Webhook注册` / `Webhook触发` / `Webhook列出` / `Webhook删除`。
- **验证**：`测试_网络钩子.light` 13 组全过 —— 注册两个钩子、列出、未注入派发器时命中但不调派发器、注入后派发器被调用且命中明细含处理器结果、一个钩子监听多事件（merge 也命中）、无匹配事件命中 0、空事件名反例、注册参数缺失三类反例、删除不存在反例、删除后不再命中、派发记录 3 条（含未注入那次）、挂载端到端、空名注册工具报错、删除不存在工具报错。
- **实现要点**：
  - 钩子记录 = `{事件列表, 处理器, 序}`；命中判据 = 事件名在监听列表里（精确相等）。
  - 派发器签名 `(处理器标识, 事件名, 负载)`；未注入时结果记为 `"(未注入派发器)"`，**仍计入派发记录**（可观测但无副作用）。
  - 触发「无匹配事件」**不算错误**（`isError=假`），只回报命中 0 个。
- **踩坑**：无新增。光明侧列表无内置 `包含`，用自建 `列表包含` 遍历实现（字典有 `.包含`，列表不能假设有）。
- **已知缺口（如实）**：
  - 无签名校验 / 无密钥 / 无重放保护（dsh 的 webhook 有 secret 校验）。
  - 无投递重试、无失败队列、无幂等键。
  - 事件匹配为**精确相等**，不支持通配符（如 `push.*`）。
