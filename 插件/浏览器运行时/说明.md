# 浏览器运行时 · 复刻任务卡

- **对标 dsh**：`packages/experimental/browser-use-runtime`
- **能力**：浏览器会话运行时：上下文/页面登记/动作队列与执行，注入式驱动
- **缺口核验**：完全无（browser-use-runtime 0 命中）；浏览器自动化 是动作层，本插件是会话运行时
- **优先级**：P8　**批次**：第 9 批　**状态**：pending
- **依赖**：浏览器自动化
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `登记页面` / `执行动作队列`。
- **与兄弟插件的关系**：**不重造动作定义**。本插件只管「上下文 → 页面 → 动作队列 → 批量执行」的
  会话运行时；单个动作长什么样由 浏览器自动化.light（动作定义层）负责，
  真实浏览器行为由注入的驱动提供（宿主可接 Playwright / DevTools）。
- **内核**：`登记上下文` / `取上下文` / `列出上下文`；`登记页面(上下文, 页面, 网址)` /
  `取页面` / `列出页面`；`入队动作(上下文, 页面, 动作, 目标, 值)`（动作限
  打开/点击/填表/截图，页面须已登记）/ `取队列` / `队列长度` / `清空队列`；
  `执行动作队列(上下文)`（逐个交驱动，**任一步失败即中止**并带出原因）/ `队列摘要` / `清空运行时`。
- **注入点**：`配置驱动(驱动)`，签名 `(动作条目) -> {"ok", "内容", "原因"}`；测试注入确定性 fake。
- **验证**：`测试_浏览器运行时.light` 20 组全过 —— 上下文/页面登记与回读、空上下文名与空页面名反例、
  未知上下文登记页面反例、未知页面入队反例、非法动作反例、入队顺序与摘要、批量执行
  （驱动逐次调用计数、结果表、页面动作数、成功后队列被消费）、空队列、未知上下文执行、
  驱动失败即中止（已执行=1/总数=3、原因含失败动作与驱动原因、队列不清空）、清空队列、
  未配置驱动反例、清空运行时归零（L-166 回归）、以及「挂载进注册表后取出工具执行」的端到端
  （含缺参报错、未知上下文报错两条反例）。
- **踩坑**：本次无新增光明缺陷。沿用既有约束：`全局 X。` 只能写在段落体内（故放在段首）；
  嵌套容器的改写一律先取局部变量再改；段内重新绑定模块级名字先声明 `全局`。
- **已知缺口（如实）**：
  - 队列**只有一条**（每上下文单队列），不做多队列/优先级/并发执行；执行严格串行。
  - 动作集合是**硬编码四项**（打开/点击/填表/截图），未与 浏览器自动化 的动作表联动校验。
  - 失败后**不重试、不回滚**：已成功的动作保持副作用，队列保留未执行部分（可由 `清空队列` 手动清）。
  - 无真实等待/超时/选择器重试策略；无页面导航栈、无 iframe、无多标签语义。
  - 上下文/页面/队列均为进程内字典，无持久化与并发锁。
