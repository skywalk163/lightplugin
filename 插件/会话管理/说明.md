## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `创建会话` / `切换会话` / `列出会话`（共 3 个）。
- **架构**：模块级 `会话表`（dict）、全局 `当前会话`、`会话序号`。
  状态机：新会话=活跃；`挂起会话`→挂起态；`恢复会话` 仅从挂起态→活跃（非挂起态恢复返回假）；
  `销毁会话`→移除并清当前指针。上下文槽为每会话内的 `槽` dict（`设槽/取槽`）。
  `列出会话` 支持按 状态 过滤（命中标志位，不用 `跳出` 避免提前 break）。
- **验证**：`测试_会话管理.light` 全绿（创建初始态、上下文槽读写、挂起→恢复状态机、多会话切换、
  不存在会话反例、状态过滤列举、销毁与重复/不存在反例、经注册表执行流水线的创建端到端 +
  缺名字 schema 拒绝）。
- **踩坑**：`字典弹出` 不是光明内置函数，真实删除要用 dict 方法 `会话表.弹出(键)`；
  `跳出` 是 break，过滤逻辑改用命中标志；`execute` 直调绕开 schema 校验，缺字段反例须走
  `注册表.执行(名字, 原始JSON)`。
- **已知缺口（如实）**：
  - 会话只存活于进程内存，无持久化；多会话并发/锁未实现（单线程纯逻辑）。
  - 切换会话不强制要求会话处于活跃态（挂起态也可被切为当前，对齐 dsh 的轻量切换语义）。
  - 无会话过期/配额策略。
