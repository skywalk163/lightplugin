## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 连接器=空)` 注册工具名 **`桌面驱动CUA协议`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`（须显式，见 LP-D-002）。

### 设计：相对 dsh 的有意差异

dsh 真实插件通过 CUA（Computer-Use Agent）MCP 上游工具驱动桌面（click / move / type / scroll / screenshot / key）。
本复刻版只复刻**翻译层**：把与设备无关的「操作意图」映射到 `mcp__cua__computer` 的 action + 规范化参数。
真实 MCP 连接由宿主注入「连接器」，不碰屏幕捕获 / 输入注入。与 `桌面驱动CUA原生` 互补（本插件带 MCP 包装，原生版无包装）。

### 验证结果

`测试_桌面驱动CUA协议.light` **8 组全部通过**：截图 / 点击(x,y) / 输入(text) / 按键(key) / 滚动(scroll_delta) / 移动 / 未知动作标跳过 / 翻译序列 / 挂载与工具（未知动作报错）。

### 已知缺口（如实）

- **不连 CUA MCP / 屏幕捕获 / 输入注入**：翻译是静态映射，不校验坐标越界、按键名合法性。
- **参数只做透传**：x / y / text / key / scroll_delta 不校验格式（如坐标是否为整数、滚动方向）。
- 不处理 multi-step（如「点击后等待」）与连续拖拽。
