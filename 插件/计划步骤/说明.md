# 计划步骤 · 复刻任务卡

- **对标 dsh**：`packages/plan`
- **能力**：线性步骤状态机：待开始 → 进行中 → 已完成，任一阶段可 → 阻塞（带原因）；支持只看未完成
- **缺口核验**：dsh 有 `packages/plan`；lightharness 侧只有内部 `计划模式.light`，**未注册成模型可调用工具** → 补门面
- **优先级**：P2　**批次**：第 11 批　**状态**：done
- **依赖**：无
- **挂接契约**：`造工具定义` + `工具注册表`

## 复刻记录

- **挂接**：暴露 5 个工具：`计划创建` / `计划开始` / `计划完成` / `计划阻塞` / `计划列出`。
- **验证**：`测试_计划步骤.light` 全过 —— 创建、开始（待开始→进行中）、完成、阻塞（带原因且出现在列出行里）、只列未完成过滤、空描述反例、不存在编号反例、已完成不可重开反例、挂载端到端。
- **实现要点**：
  - 状态存字符串字面量：`待开始` / `进行中` / `已完成` / `阻塞`。
  - 状态迁移**不做合法性拦截**（除「已完成不可重开」），与 dsh 计划模式的宽松语义一致。
  - 「列出」为行列表，`阻塞` 态追加 `原因=...`。
- **踩坑**：无新增。
- **已知缺口（如实）**：
  - 步骤间**无依赖边**（dsh 的 plan 支持步骤依赖排序），本插件只有自增序号，未建图。
  - 阻塞后需显式 `计划开始` / `计划完成` 才能离开阻塞态，无自动解除。
  - 持久化同 待办清单：宿主注入，未注入即纯内存。
