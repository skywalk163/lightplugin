## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 采集器=空)` 注册工具名 **`运行检视`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`、`从 内置核心字典 导入 字典键列表`（均须显式，见 LP-D-002）。

### 设计：相对 dsh 的有意差异

dsh inspector 是 Chrome DevTools 检查器（CDP / WebSocket / 浏览器 realm），真实运行时采集依赖浏览器。
本复刻版只复刻**纯逻辑核心**：节点表（上下文树）+ 观测记录表由本模块持有与计算；真实采集由宿主注入「采集器」，不碰 CDP、不碰浏览器 → 单测零网络、零浏览器依赖。

### 踩到的坑（本批次最多）

1. **list/dict 类型混用（自查，非语言缺陷）**：`取快照` 最初把节点 `属性`（dict）转成 `[{"键":..,"值":..}, ...]` list，而 `取节点属性` 按 dict 调 `字典键列表` → `类 list 缺少方法/属性 keys`（内置核心字典:29）。修：`取快照` 的 `属性副本` 改建为 dict。
2. **多级索引误拆**：早期 `节点表[序号]["属性"][键]` 一步多级索引，配合 1. 的 list 误用报 `list indices must be integers or slices, not str`。修：拆成 `设 项 为 节点表[序号]; 设 属性表 为 项["属性"]; 属性表[键] 为 值`。（**更正**：多级索引 `A[B][C]` 光明本就支持，见 LP-D-007；真因是 list 当 dict。）
3. **LP-D-009（未定性）**：`取节点属性` 最初在 for 内有提前 `返回 空`，导入时报 `cannot import name '取差异'`（后续顶层段落疑似被吞进前一函数体）。改写为「去掉 for 内提前返回 + 迭代源先赋临时变量 `键表`」后导入恢复。**当前编译器无法 minify 复现，疑已修复**，见 LP-D-009。
4. **测试断言写反（自查，非语言缺陷）**：第 7 段显式旧快照差异，旧快照是当前的子集（缺 客户端乙），`客户端乙` 应落 `新增` 而非 `移除`；原测试误写成断言 `移除 包含 客户端乙`。修：改为断言 `新增 包含 客户端乙` 且 `移除 为空`。

### 验证结果

`测试_运行检视器.light` **9 组全部通过**（经 `运行.py` unified 生成器）：登记上下文（含重复登记失败）/ 设属性（含不存在上下文失败）/ 发布观测序号与观测数 / 快照字段 / 与基线差异-新增 / 与基线差异-变化 / 显式旧快照差异-新增&移除方向 / 导出 / 挂载与工具（含未知动作报错）。

### 已知缺口（如实）

- **不做 CDP / 浏览器 realm 采集**：只吃宿主注入的采集器，不接真实浏览器。
- **差异只比属性键值对**：不比节点树结构层级变化（父节点变更），不比观测记录内容变化。
- **快照/导出为内存结构**：不做 JSON 序列化落盘（宿主侧负责），不持久化历史快照。
