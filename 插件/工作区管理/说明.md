# 工作区管理 · 复刻任务卡

- **对标 dsh**：`packages/workspace`
- **能力**：工作区/根目录管理：多根注册 + 解析相对路径到根 + 根切换
- **缺口核验**：完全无（workspace 0 命中）；工具_路径安全只做单根校验
- **优先级**：P6　**批次**：第 7 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`

## 复刻记录

- **挂接**：`造工具定义` → `工具注册表`；暴露工具 `注册工作区`（名字→绝对路径）与 `解析路径`（相对路径解析到指定根并经存在性判定校验）。存在性判定为注入式函数（绝对路径→布尔），零真实文件系统依赖。
- **验证**：`测试_工作区管理.light` 全过（列出根、首注册成为当前根、根切换、切换未知根失败、路径拼接归一化、解析存在、未知根报错、路径不存在报错、挂载端到端）。
- **踩坑**：① 同前，避免字符串花括号插值；② `子串位置`/`字典键列表` 须导入；③ `切片` 非全局函数，改用 `[起:止]` 索引切片语法（与 网页抓取 一致）；④ 段落内改写模块级标量 `当前根`/`默认存在性判定` 须先写 `全局 X。`，否则静默变局部导致切换/注入失效。
- **已知缺口（如实）**：
  - 路径拼接为简单字符串归一（去反斜杠/多余斜杠），非 dsh 基于真实 OS 的路径解析（符号链接、相对 `..` 跨根越界未处理）。
  - 存在性判定完全依赖宿主注入；本插件不内置任何真实磁盘访问，纯逻辑层不保证与真实文件系统的语义一致。
