# 技能运行时 · 复刻任务卡

- **对标 dsh**：`packages/skill（运行时）`
- **能力**：SkillProvider{name,list,get} + 渐进加载 + 执行
- **缺口核验**：仅静态 技能清单.light，缺运行时
- **优先级**：P0　**批次**：第 1 批　**状态**：pending
- **依赖**：无
- **挂接契约**：`造工具定义(名字, 描述, 参数, 执行函数, ...)` + `工具注册表`；需宿主服务时用 `绳构造注册` / `绳装配`
