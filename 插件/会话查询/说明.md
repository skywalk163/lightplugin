## 复刻记录

- **挂接方式**：`从 工具 导入 造工具定义, 造工具结果`，导出 `挂载(注册表)` 注册 1 个工具「查询会话」。
  会话源由宿主/测试经 `注入会话源(取源函数)` 注入 → 零真实会话依赖、零网络、零计时。
- **实现要点**：`过滤会话(源, 条件)` 支持「状态」精确匹配 + 「关键字」包含匹配（AND 组合）；
  `分页(表, 页码, 每页)` 切片分页（越界返回空表，不报错）；
  `抽取字段(表, 字段表)` 字段表为空时返回整条；`查询会话(条件,页码,每页,字段表)` 为三者编排。
- **踩到的坑（均已修）**：
  1. **LP-D-013**：变量名取「出」时 `出.追加(...)` 解析失败（报「无法识别的语法元素 '.'」），
     而 `设 出 为 []` / `返回 出` 却正常——关键字根 + 成员访问同族问题。已改名 `抽取表`。
  2. **L-166 影子变量**：测试 `主` 内给模块级 `假源数据` 赋值却未声明 `全局`，模块级那份仍是空表，
     过滤恒为 0（**静默错**，编译只给告警）。已改为在 `假源()` 段落内直接构造数据，消除同名影子。
- **验证结果**：`测试_会话查询.light` 10 组断言全绿（状态过滤 / 关键字过滤 / 组合条件 / 分页 /
  字段抽取 / 空字段表返回整条 / 编排端到端 / 注册+execute 端到端 / 空结果反例 / 分页越界反例）。
- **已知缺口（如实，不谎报对齐度）**：
  - 过滤仅支持「状态」精确 + 「名字」包含两类条件，未做通用表达式或正则。
  - 分页为内存切片，非游标分页；超大数据集不适用。
  - 本插件不感知真实会话生命周期（那是 `会话管理` 插件的职责），只消费注入的会话源。
