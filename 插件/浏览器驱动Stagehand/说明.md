## 复刻记录

### 挂接方式

- 复用 `工具.light` 的 `造工具定义` / `造工具结果`；导出 `挂载(注册表, 连接器=空)` 注册工具名 **`浏览器驱动Stagehand`**。
- 跨模块导入：`从 字符串处理 导入 子串位置`（须显式，见 LP-D-002）。

### 设计：相对 dsh 的有意差异

dsh 真实插件通过 Stagehand（playwright + 视觉模型）驱动浏览器，动作语义是**自然语言指令**而非精确选择器。
本复刻版只复刻**翻译层**：把动作意图映射到 Stagehand 的 `act` / `extract` 调用结构（工具名 + 参数，`instruction` 为自然语言）。
真实 Stagehand 运行时由宿主注入「连接器」，不碰浏览器进程。与 `浏览器驱动Playwright` / `浏览器驱动DevTools` 互补（三者都是「动作序列的方言翻译」）。

### 验证结果

`测试_浏览器驱动Stagehand.light` **9 组全部通过**：打开→`stagehand.act(goto)` / 点击→`act(click, instruction 含选择器)` / 填表→`act(fill)` / 抽取→`stagehand.extract` / 截图 / 滚动 / 未知动作标跳过 / 翻译序列 / 挂载与工具（未知动作报错）。

### 已知缺口（如实）

- **`instruction` 为简单拼装的自然语言字符串**：未做选择器转义 / 语义优化；真实 Stagehand 自行定位元素。
- **不连 Stagehand 运行时 / 浏览器**：不校验 selector 有效性、不等待策略。
- 参数只做透传（url / selector / text / 量 不校验格式）。
